# Mailbox Outstanding Map

An interactive review map for outstanding mailbox items, grouped by shared topic keys such as award numbers, project numbers, tickets, and invoices.

The full map provides:

- search across topics, identifiers, subjects, senders, and excerpts
- status and bucket filters
- a priority board for reviewed action items
- a complete live-cluster inventory
- cluster deletion with restore; deletions are saved in your browser

The compact summary provides the same reviewed priorities in a simpler, sectioned layout.

View the site at: <https://wujin31.github.io/mailbox-outstanding-map/>

A public demo of the latest SPF Mailbox Map interface, generated from the synthetic test inbox, is available at:
<https://wujin31.github.io/mailbox-outstanding-map/demo/>

The refresh companion is intentionally unavailable in the public demo. A live refresh requires the localhost companion started by `RUN-MY-MAILBOX-MAP.bat`, which reads Outlook on the accountant's own computer. Do not publish a generated mailbox board to GitHub Pages because it contains confidential mailbox content.
